# Шаг 17 — Возврат распарсенного вывода аналитики и ограничение технических статусов для админа

Дата: 2026-04-05

## Что сделано
- На странице результатов сохранён пользовательский режим «чистого» аналитического вывода (распарсенный `analysis_text`).
- Техническая диагностика (статусы запуска анализа, fallback-warning, факт взаимодействия с LLM, статус валидации и сырой ответ LLM) оставлена только для администраторов (`request.user.is_staff`).
- Улучшен парсинг `rating`:
  - если LLM возвращает `rating` строкой (например, `"3"`), парсер приводит его к `int`.
- Добавлен тест на корректный разбор JSON со строковым `rating`.

## Что не сделано в этом шаге
- Не менялись модели и миграции.
- Не менялась логика диалогового lifecycle.
