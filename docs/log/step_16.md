# Шаг 16 — Диагностика аналитики, UX отправки в чате, энциклопедия и отключение PDF-кнопок

Дата: 2026-04-05

## Что сделано
- Экран результатов аналитики расширен диагностикой LLM:
  - добавлен статус запуска анализа и число попыток LLM;
  - по каждому критерию показывается факт взаимодействия с LLM (да/нет);
  - выводится «сырой ответ LLM» без обработки в `pre`-блоке.
- В чате изменена последовательность UX отправки:
  - реплика пользователя сразу добавляется в ленту;
  - затем выполняется запрос к LLM;
  - после ответа добавляется реплика ассистента.
- Для энциклопедии:
  - в списке отображаются заголовок + краткое описание;
  - в детальной странице краткое описание сохраняется и отображается перед текстом статьи;
  - возвращён фильтр только опубликованных статей, чтобы переключатель «Опубликовано» в админке реально влиял на видимость пользователю.
- Исправлена обязательность краткого описания в админке:
  - поле `summary` у `EncyclopediaArticle` стало опциональным (`blank=True`);
  - валидация длины summary применяется только если summary заполнен;
  - автогенерация summary при сохранении в админке отключена (summary можно оставить пустым).
- Исправлены кнопки PDF:
  - убрана кнопка экспорта PDF со страницы результатов;
  - убрана кнопка PDF из истории в личном кабинете.

## Что не сделано в этом шаге
- Логика backend endpoint-а PDF сохранена (кнопки убраны только из UI).
- Не менялись роли/права доступа.
