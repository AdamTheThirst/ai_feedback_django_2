# Шаг 15 — UX чата, overlay анализа, устойчивость JSON-аналитики и фикc энциклопедии

Дата: 2026-04-05

## Что сделано
- Убрано сообщение статуса LLM из ленты чата (по запросу).
- Условия сценария перенесены в область ленты как первое сообщение диалога, чтобы они прокручивались вверх вместе с историей и не занимали фиксированное место вверху экрана.
- Кнопка «Дай обратную связь» переведена в стиль белой кнопки с оранжевой обводкой (`btn-outline-warning`).
- После нажатия «Дай обратную связь» показывается центрированный overlay:
  - текст «Идёт анализ диалога. Это может занять некоторое время, пожалуйста, подождите»;
  - небольшая анимация-спиннер.
- Улучшена устойчивость аналитики к ответам LLM в markdown-обёртке:
  - добавлена нормализация текста ответа перед `json.loads` (поддержка ```json ... ``` и текста вокруг JSON).
- Исправлена ошибка энциклопедии `NoReverseMatch` для unicode slug:
  - URL-паттерн детальной страницы переведён с `<slug:slug>` на `<str:slug>`.
- Обновлены тесты:
  - добавлен тест на markdown-wrapped JSON в аналитике;
  - обновлены тесты чата и энциклопедии в рамках предыдущего шага.

## Что не сделано в этом шаге
- Не менялись модели и миграции.
- Не менялась PDF-логика.
