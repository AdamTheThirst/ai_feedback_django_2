# Шаг 14 — LLM в чате без заглушек + видимость энциклопедии для пользователя

Дата: 2026-04-05

## Что сделано
- Полностью заменён временный LLM-стаб на реальный OpenAI-compatible клиент в `apps/integrations/services/llm_chat.py`.
- Подключены переменные из `.env`:
  - `LLM_API_KEY`
  - `LLM_BASE_URL`
  - `AI_MODEL_NAME`
  - `LLM_TIMEOUT_SECONDS`
- Добавлена обратная совместимость по legacy-ключам `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL`, `AI_TIMEOUT_SECONDS`.
- В чате добавлен вывод статуса подключения к LLM **перед ответом ассистента**:
  - backend возвращает `llm_status_text` в JSON;
  - frontend вставляет эту строку в ленту перед bubble ответа персонажа.
- Убрана «заглушечная» генерация игрового ответа: теперь ответ персонажа идёт только через LLM-вызов.
- При технической недоступности LLM API возвращает контролируемую ошибку `LLM недоступен: ...`.
- Исправлена видимость энциклопедии: пользовательский список и детальная страница теперь показывают статьи из админки без фильтра `is_published=True`.
- Обновлены тесты:
  - `apps/dialogs/tests/test_send_message_api.py` — мок LLM и проверка `llm_status_text`;
  - `apps/content/tests/test_encyclopedia.py` — ожидаемая видимость статей из админки.

## Что не сделано в этом шаге
- Не вносились изменения в модели и миграции.
- Не менялись роли/доступы административного контура.
