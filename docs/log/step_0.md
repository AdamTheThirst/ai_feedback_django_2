# step_0

## Операции, выполненные на шаге
1. Инициализирован файловый каркас Django-проекта.
2. Созданы конфигурационные файлы `manage.py`, `config/*`, `config/settings/*`.
3. Созданы пакеты приложений `apps/*` с `apps.py` и базовой регистрацией.
4. Добавлены шаблоны `base` и `home`, подключены Bootstrap и локальные static-файлы.
5. Добавлен `.env.example` с переменными AI/email.
6. Добавлены служебные файлы `requirements.txt`, `.gitignore`.
7. Добавлен общий лог `docs/log/build_log.md`.

## Какие функции появились и зачем
- `manage.py::main()` — единая точка запуска Django-команд.
- `static/js/app.js::initApp()` — техническая точка расширения клиентской логики (пока без продуктового поведения).

## Связность между элементами
- `config/settings/*` предоставляет единый источник настроек для всех будущих модулей.
- `templates/layouts/base.html` подключает общие стили/скрипты и станет основой пользовательских экранов.
- `apps/*/apps.py` регистрирует модули, чтобы в следующих шагах добавлять модели/сервисы без перестройки структуры.

## Краткий консольный отчёт
Bootstrap-слой создан: конфигурация проекта, каркас приложений, базовый UI-слой и `.env`-контракт подготовлены.
