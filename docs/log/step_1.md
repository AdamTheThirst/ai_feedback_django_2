# step_1

## Операции, выполненные на шаге
1. Добавлены базовые абстрактные модели в `apps/core/models.py`.
2. Добавлены enum-статусы диалога и анализа в `apps/core/enums.py`.
3. Созданы базовые модели `DialogSession` и `AnalysisRun`.
4. Добавлены миграции `0001_initial` для `dialogs` и `analysis`.

## Какие функции/сущности появились и зачем
- `TimestampedModel` — унификация технических timestamp-полей.
- `ArchivableModel` — подготовка механизма архивирования мастер-данных.
- `PublicIdModel` — единый UUID для внешней идентификации.
- `DialogSession` — базовый жизненный цикл игрового диалога.
- `AnalysisRun` — технический жизненный цикл запуска аналитики.

## Связность между элементами
- `AnalysisRun` всегда привязан к одной `DialogSession`.
- `DialogSession.status` и `AnalysisRun.status` используют централизованные enum из `core/enums.py`.
- Частичный уникальный индекс по `DialogSession(user, status=active)` предотвращает одновременные активные сессии пользователя.
